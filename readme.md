# SONIC VANE

Sonic VANE (LS5 Engine 3) is a physics-sandbox-styled action platformer framework built on the Godot engine.  It is a sequel to my final BlitzSonic mod, LS5 Engine 2.

We encourage anyone to use our framework in any way, even in their own projects.  If you would like to contribute to Sonic VANE's development, or even simply make your own custom levels, characters, or other assets, go ahead and play around as you see fit!  Our goal is to re-kindle the creative spirit and community that BlitzSonic sparked in 2008.
